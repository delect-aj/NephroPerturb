Examples

# Deterministic Agent runner (0-LLM rules mode)
curl -X POST http://<host>:8091/api/v1/agent/run \
  -H "Content-Type: application/json" \
  -d '{"text":"Find reversal drugs for the DKD glomeruli case","use_llm":false}'

# Direct signature reversal query
curl -X POST http://<host>:8091/api/v1/query/signature \
  -H "Content-Type: application/json" \
  -d '{"up_genes":["COL1A1","TGFB1"],"down_genes":["NPHS1","PPARA"],"top_k":20}'

Deterministic Agent SOP Rules

NephroAgent does not invent plans or numbers. It routes natural language deterministically across six pre-registered SOPs and invokes the corresponding backend tool.

Reproducibility & Grounded Verification

Every query returns a unique job_id and provenance record (input hash, parameters, matrix version, UTC timestamp) stored in job_provenance. Without DEEPSEEK_API_KEY, all routes run in 0-LLM mode. Any optional LLM summary passes through an entity + number verifier and falls back to the deterministic template if any mismatch is detected.
