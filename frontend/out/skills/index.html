Shared Safeguards Across All 6 Skills

Enforced identically in DeepSeek ReAct and 0-LLM Multi-Step modes
Scoped Determinism
DeepSeek ReAct runs at temperature=0.0, seed=42, restricted strictly to each Skill's allowed tools and step cap.
7-Day Evidence Cache
Title/Abstract Europe PMC (PubMed fallback) and ClinicalTrials.gov v2 queries are cached for 7 days in SQLite.
Grounding Verifier
Audits every PMID, NCT, BRD ID, and score against live tool outputs with 1x surgical repair or deterministic fallback.
Auto-Built References
Numbered bibliography entries and table footnotes are assembled directly from verified tool metadata with zero extra tokens.
